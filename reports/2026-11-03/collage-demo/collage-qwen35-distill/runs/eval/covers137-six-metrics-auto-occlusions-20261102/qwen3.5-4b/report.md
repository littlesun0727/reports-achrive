# 六项评测 v3

IoU≥0.50的一对一配对视为找到。主分先逐图计算再取均值；GT范围固定，失败不会从有GT的分母中剔除。
已找到框IoU只看有匹配的图片，须与召回率一起看；不是所有GT框的定位分。固定元素内部不要求overlay/text/frame类别一致。

| 关注项 | 固定GT范围 | 结果 |
| --- | --- | --- |
| 1. JSON结构通过率 | 137张 | 首次 32.85%；复检后 86.86% |
| 2. photo 找到多少、框多准 | 137张 · 568个GT元素 | 召回 77.66%；已找到框IoU 0.889 |

| 4. 重叠元素顺序一致率 | 133张 · 1732对固定GT关系 | 40.90% |
| 5. frame 是否连上、是否全部连对 | 38张 · 92个GT frame | 连上 28.68%；全部连对 25.18% |
| 6. linked_to 出框是否识别正确 | 3张 · 3个GT出框主体 | 0.00% |

顺序只检查occlusions.jsonl中固定的元素对；当前GT按bbox正面积重叠及GT layer_order一次生成，不比较互不相交元素的顺序。bbox重叠是遮挡的近似，透明区域可能产生例外。frame全部连对要求照片集合完全一致；linked_to要求主体及来源都对应。
JSON结构通过包含语法、字段、ID和引用契约；不是视觉准确率。复检后为主批次最终交付，并非只在首次失败样本中统计。

多报与错误分解保留在primary.diagnostics及per_sample.jsonl的focused_metrics中，不合成额外总分。
